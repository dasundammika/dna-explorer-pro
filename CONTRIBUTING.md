# Contributing to DNA Explorer Pro

Thanks for helping make molecular science more accessible.

- Check existing issues before opening a new one.
- For bugs, provide reproduction steps, a DNA sequence or PDB snippet where relevant, and browser/version details.
- For scientific corrections, cite a primary source or reputable structural biology reference and distinguish schematic from experimental coordinates.
- Submit small pull requests with tests for changes to sequence or geometry calculations.
- Run `bun run lint`, `bun test src/engine/dnaEngine.test.ts`, and `bun run build` before opening a pull request.
- Never commit `.env` files or API credentials.

Respectful feedback and contributions are welcome.
